# unicorne

A unibody [Corne](https://github.com/foostan/crkbd) keyboard: both halves on a single PCB, each half rotated with a slight tilt.

Status: project skeleton, nothing designed yet.

## Tools

- KiCad 10.0 (open `unicorne.kicad_pro`)

## Layout

| `unicorne.kicad_pro` | KiCad project |
